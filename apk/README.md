Este é o APK para instalação direta no ANDROID
Normalmente o ANDROID **não** permite a instalação destes programas

Siga os passos a seguir:

No celular/tablet de destino, acesse o gerenciador de arquivos (ou o WhatsApp/Drive) e toque no arquivo LoRa_SOS.apk.

O sistema exibirá o aviso:

"Por motivos de segurança, o seu smartphone não tem permissão para instalar apps desconhecidos desta fonte."

Toque em Configurações na própria mensagem de alerta.

Ative a opção "Permitir desta fonte" (ou "Autorizar instalações de apps desconhecidos").

Volte à tela anterior e toque em Instalar.

Pronto! O aplicativo LoRa SOS será instalado com o ícone personalizado, nome oficial e estará pronto para ser usado e demonstrado em campo.
